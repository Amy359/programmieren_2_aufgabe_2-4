# README - PowerOriginal (Power-Curve Auswertung)

Dieses Projekt enthält ein Python-Programm zur Analyse von sportlichen Aktivitätsdaten. Es berechnet die maximale Durchschnittsleistung für verschiedene Zeitintervalle (Power-Curve) und visualisiert die Ergebnisse.

## Verwendete Leistungsspalte

* **Power Curve Name / Spalte:** `PowerOriginal`

## Voraussetzungen & Installation

Das Projekt verwendet **PDM** zur Verwaltung der Abhängigkeiten (wie Pandas und Matplotlib).

1. Öffne den Projektordner in VS Code.
2. Installiere alle benötigten Bibliotheken über das Terminal:
   ```bash
   pdm install

pdm run python advanced_powercurve.py
